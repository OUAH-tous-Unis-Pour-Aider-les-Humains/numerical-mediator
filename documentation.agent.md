# Agent context — documentation

## Objectif
- Produire une documentation claire pour humains et IA.

## Règles de rédaction
- Écrire en français par défaut.
- Utiliser des sections courtes avec titres explicites.
- Préférer des listes actionnables et des exemples concrets.
- Lier les documents entre eux (`README.md`, `CONTRIBUTING.md`, `docs/`).

## Qualité
- Séparer faits, explications et guides pratiques.
- Éviter le jargon non expliqué.
- Appliquer des changements ciblés sur la demande.
