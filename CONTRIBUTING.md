# Guide de contribution

Merci de contribuer à **numerical-mediator**.

## Démarrage rapide
1. Forker puis cloner le dépôt.
2. Créer une branche dédiée depuis `main`.
3. Faire un changement ciblé (petit incrément).
4. Vérifier localement ce qui est disponible dans ce dépôt.
5. Ouvrir une Pull Request avec une description claire.

## Workflow recommandé (humain + IA)
1. Ouvrir une issue avec contexte, problème et résultat attendu.
2. Demander une proposition IA sur un périmètre réduit.
3. Relire chaque changement (code et documentation).
4. Ajouter/mettre à jour les tests quand une infrastructure de tests existe.
5. Mettre à jour la documentation liée.

## Conventions
- Commits : style **Conventional Commits** (`feat:`, `fix:`, `docs:`, etc.).
- PR : utiliser le template de Pull Request.
- Sécurité : suivre [`SECURITY.md`](./SECURITY.md), ne jamais publier de secret.
- Conduite : suivre [`CODE_OF_CONDUCT.md`](./CODE_OF_CONDUCT.md).

## Besoin d’aide
- Utiliser l’onglet Discussions pour échanger sur l’architecture et les choix de mise en œuvre.
