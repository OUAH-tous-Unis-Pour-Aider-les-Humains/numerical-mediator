# Politique de sécurité

## Versions supportées
Ce dépôt est en phase de cadrage. Les corrections de sécurité sont appliquées sur la branche active principale du projet.

## Signaler une vulnérabilité
Merci de **ne pas** ouvrir d’issue publique pour une vulnérabilité potentielle.

Utilisez un canal privé mainteneur (message privé GitHub ou Security Advisory GitHub si activé) en incluant :
- description de la vulnérabilité ;
- impact estimé ;
- étapes de reproduction ;
- proposition de correction si disponible.

Nous accusons réception dès que possible et priorisons les vulnérabilités critiques.
