# ADR-0001 : Cadre de collaboration humain + IA

**Date** : 2026-03-19  
**Statut** : Accepté

## Contexte

Le projet souhaite préparer la contribution assistée par IA (Copilot et Coding Agent) tout en conservant une revue humaine et un cadre de qualité explicite.

## Décision

Le dépôt adopte un socle minimal de gouvernance :
- instructions Copilot au niveau repository ;
- guide de contribution ;
- templates d’issues et de Pull Request ;
- politique de sécurité et code de conduite.

## Conséquences

- Les contributions humaines et IA sont mieux cadrées dès l’ouverture d’une issue.
- Les attentes de qualité et de sécurité sont explicites.
- Le projet reste léger : documentation et processus d’abord, outillage supplémentaire ensuite si nécessaire.
