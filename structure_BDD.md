# La base de donnée est séparée en 5 grandes parties : classification, hypothèse, donnée, source et maths.

## classification sera allimenté par les données de wikidata, elle contient pour chaque objet :

- une référence à l'objet wikidata
- un nom en français pour l'affichage
- une définition sous la forme :
  - d'une formule latex
  - de références envers  d'autres objet wiki data pour remplacer les variables dans le latex
- une nature : si c'est un nombre, un ensemble, une unité, etc. ...

On utilise pour la science des hypothèses.

## un hypothèse posséde :

- une formule mathématique en latex
- des références permettant de faire le lien entre un élément de classification et les lettres (varaibles) dans la formule latex
- les références des objets expérimentation pour
- les référence des objets expérimentation contre
- un statut (un coefficient décrivent la confience en cette hypothès)

On utilise pour l'expérimentation une répartition en objets source et objets données. Les source doivent être lié aux objets données qu'elles engendre et réciproquement, les objet données doivent être lié au sources qui les appuient. Aussi, les données qui ont des sujets en commun doivent être liés entre elles.

## une source possède :

- une date (format de date)
- un lieu
- un auteur
- un environnement (contient le cadre dans lequel provient la source : laboratoire, citation, interview, etc.)

## une donnée possède

- un contenu (une phrase ou une liste, un tableau)

## maths contient une formule mathématiques de prédicat en latex

- un intitulé comme "addition"
- un symbole correspondant comme "+" ou "\forall"
- une démonstration qui référence d'autres prédicats déjà découverts en utilisant leur symbole ou leur intitulé si il n'y a pas de signe
- on séparera les axiomes des autres  prédicats
