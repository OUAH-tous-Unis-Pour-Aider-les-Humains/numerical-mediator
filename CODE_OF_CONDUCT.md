# Code de conduite

Ce projet adopte les principes du [Contributor Covenant](https://www.contributor-covenant.org/) (v2.1).

## Notre engagement
Nous nous engageons à maintenir un espace accueillant, respectueux et constructif pour toutes les personnes qui contribuent.

## Comportements attendus
- Utiliser un langage bienveillant et inclusif.
- Respecter les différences de points de vue et d’expérience.
- Accepter les retours de manière constructive.
- Se concentrer sur l’intérêt du projet et de la communauté.

## Comportements inacceptables
- Harcèlement, intimidation ou propos dégradants.
- Attaques personnelles et comportements perturbateurs répétés.
- Publication d’informations privées sans consentement.

## Application
Les mainteneurs peuvent modérer les échanges et contributions en cas de non-respect de ce code.
